# 장전 뉴스 브리핑 — 구성표

매일 평일 아침 Claude 예약 작업이 이 파일을 읽고 그대로 따른다.
항목을 늘리거나 바꾸고 싶으면 정훈이 Claude에게 "브리핑에 ○○ 추가해 줘"라고 말하고, Claude가 이 파일을 고친다. (다음 날부터 반영)

## 목차
1. 받는 곳·시각
2. 자료 모으기 순서
3. 메시지 구성 (이 순서대로)
4. 쓰는 규칙
5. 바뀐 기록

## 1. 받는 곳·시각
- 평일 08:15쯤 작성 시작 → 08:25쯤 텔레그램 '같이 보는 방'(아버지와 공유)에 도착
- 기존 08:30 숫자 장전 브리핑(데스크톱 3_시장알림)은 그대로 두고, 이 메시지는 "왜"와 "어디로 돈이 갈지"를 맡는다
- 휴장일(프리마켓 체결 없음)에는 보내지 않는다

## 2. 자료 모으기 순서
1. `python tools/premarket.py` — 프리마켓(08:00~) 오른·내린 종목, 강한·약한 테마, 지수 20·60일선 위치, 어제 강한 테마
   - 결과가 "휴장"이면 여기서 끝낸다 (파일을 만들지 않음)
2. 뉴스 검색 (각각 따로 검색)
   - 간밤 뉴욕증시 마감과 이유 (나스닥·S&P500·다우·필라델피아 반도체지수, 크게 움직인 종목)
   - 미국에서 강했던 업종과 이유 (인수합병·실적·정책 등)
   - 오늘 국내 증시 전망 기사 (증권사 연구원 코멘트: 키움 한지영, 미래에셋 서상영 등)
   - 오늘 프리마켓 기사 ("넥스트레이드 프리마켓" 특징주)
   - 이번 주 일정 (금통위·FOMC·CPI·PCE·옵션만기·주요 실적·관세 발표 등)
   - 원/달러 환율 전망
3. 프리마켓 강한 테마가 뉴스 어떤 재료와 연결되는지 맞춰 본다 (재료가 안 보이면 "재료 미확인")

## 3. 메시지 구성 (이 순서대로)
```
🗞 장전 뉴스 분석  MM/DD
━━━━━━━━━━━━━━
🎯 한 줄 결론: (오늘 장 방향 + 주도 예상 한 줄)

🌎 밤사이 무슨 일 (3줄 이내)
- 지수 숫자는 짧게, "왜"를 중심으로

🇰🇷 오늘 장 예측
- 시초가 예상 (야간선물·프리마켓 대형주 등락 근거)
- 장중 흐름 예상 (증권사 전망 요약, 출처 언론사명)

💰 돈이 몰릴 곳 (프리마켓 실제 데이터 + 뉴스 재료)
1순위 업종 — 근거 / 프리마켓 강한 종목 3~5개 (등락률)
2순위 업종 — 근거 / 종목
3순위 (있으면)
⚠️ 피할 곳 — 프리마켓 약한 테마, 어제 급등 후 되밀릴 곳

👑 주도주 후보 (프리마켓 기준, 관찰용)
- 테마별 대장 1~2개씩, 최대 6개 — "확인 방법: 09:00~09:30 거래대금 상위에 같은 테마 2~3개 이상"

📅 오늘·이번 주 일정 (2~4줄)

🧭 원칙으로 보면
- 지수 20일선 위/아래 → 종가베팅·CAN SLIM 신규 매수 가능/쉼, 저가매수는 신호대로
- 추격 매수 금지 한 줄

출처: 언론사명 나열 (링크 없이)
ℹ️ 정보용 추정 — 매수 추천 아님
```

## 4. 쓰는 규칙
- 휴대폰 한두 화면 (대략 40줄 이내). 쉬운 한국어, 전문용어는 풀어서
- 숫자는 기사·프리마켓 자료에 있는 것만 쓴다. 지어내지 않는다
- 업종·종목은 "추정" "관찰용"으로 쓰고, 사라고 권하지 않는다 (아버지도 보는 방)
- 기사 문장을 그대로 길게 옮기지 않고 요약한다
- 텔레그램 서식 없이 일반 글 (이모지·줄바꿈만)
- 개인 보유 종목·계좌 이야기는 쓰지 않는다 (공유 방)
